# 🧟 WALKER MAP — 생존 전략 지도

워킹데드에서 영감을 받은 **좀비 아포칼립스 생존 전략 지도**입니다.
실제 지도(OpenStreetMap) 위에서 내 주변의 마트·경찰서·병원·아파트·교도소 등을 찾아
**워커(좀비) 수와 위험도, 남은 물자**를 추정하고, 거점과 약탈 루트를 짤 수 있습니다.

> 순수 HTML/CSS/JS 정적 웹앱입니다. 빌드 과정이 없고 서버도 필요 없습니다.

## 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages에 올리면 바로 동작합니다 (Settings → Pages → 브랜치 선택).
`내 위치` 기능은 브라우저 정책상 **https 또는 localhost**에서만 동작합니다.

## 기능

### 📡 정찰 (지역 분석)
- 지도를 원하는 곳으로 옮기고 **이 지역 정찰** → 반경(500m~3km) 내 장소를 OpenStreetMap에서 수집
- 23종 장소 분류: 마트·편의점·음식점·농장 / 경찰서·군부대·총포사·철물점·소방서 / 병원·**의과대학**·약국·의원 / 주유소 / 교도소·대피소·지하철역·교회·대학교·학교 / 아파트·주택 / 공원
- 장소마다 **추정 워커 수 · 생존자 수 · 위협도 · 남은 자원(식량/물/의약품/무기/도구/연료/은신)**
- **생존 지수**(0~100): 남은 물자 대비 워커 밀도
- 기준점(거점 → 내 위치 → 정찰 중심)에서 **가장 가까운 식량·의약품·무기·연료·은신처** (방향+거리)
- **추천 거점**: 방어력·은신 가치·주변 자원 접근성 − 내부/주변 워커
- **약탈 우선순위**: 필요한 자원 ÷ 위험 ÷ 거리
- **위험 구역**: 워커가 가장 많이 몰려있을 곳

### ⏳ 시나리오
- **경과일**: Day 1(발생 직후) / Day 7(붕괴) / Day 30(무법지대) / Day 180(새 질서)
  — 감염률이 오르고, 약탈로 물자가 줄어듭니다. 경찰서·교도소처럼 털기 어려운 곳은 물자가 더 오래 남습니다.
- **주간/야간**: 학교·대학·지하철역은 낮에, 아파트·주택은 밤에 사람이 많습니다 → 워커 분포가 달라집니다.

### 🧭 작전
- **거점 지정**: 장소 팝업 또는 지도 클릭
- **약탈 루트**: 경유지를 추가하면 왕복 거리, 소요 시간(도보 4km/h + 수색 15분/곳), 경로상 **조우 예상 워커**, 루트 위험도, 예상 획득 자원 계산
- **순서 최적화**: 최단 경로 순서로 자동 정렬
- **전술 마커**: 위험 지대 ☠️, 집결지 🚩, 은신처 ⛺, 함정/바리케이드 🚧, 물자 은닉 📦, 메모 📝 (드래그 이동 가능)
- **작전 파일 내보내기/가져오기**(JSON)로 동료와 공유

### 🎒 보급
- 인원·식량·물·구급키트·탄약·근접무기·연료 입력 → **버틸 수 있는 일수** 계산
- 부족한 자원일수록 **약탈 우선순위 가중치**가 올라갑니다

모든 작전 데이터는 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 구조

```
index.html          화면 구성
css/style.css       스타일 (다크 테마, 모바일 바텀시트)
js/categories.js    장소 종류별 자원·인원·위험·방어력 데이터, OSM 태그 분류
js/overpass.js      OpenStreetMap(Overpass API) 수집 + 오프라인 데모 도시, 장소 검색(Nominatim)
js/analysis.js      위협도·생존지수·거점·루트 계산 (DOM 독립)
js/app.js           지도(Leaflet)·UI·상태 저장
vendor/leaflet/     Leaflet 1.9.4 (BSD-2)
```

수치를 바꾸고 싶다면 `js/categories.js`의 `people`, `risk`, `defense`, `stash`, `resources`와
`SCENARIOS`를 조정하세요.
