# SURVIVOR — 민간인 생존 앱

전쟁·무력충돌·대형 재난 지역의 민간인이 **인터넷 없이** 쓰는 생존 앱 (Flutter, 안드로이드 우선).
설계 원칙·구조·데이터 소스는 [`CLAUDE.md`](CLAUDE.md), 화면 목업은 [`docs/mockups/`](docs/mockups/).

## 화면

| 축 | 화면 |
|---|---|
| 홈 | 지금 필요한 것, 가장 가까운 대피소, SOS, 언어 |
| 지도 | 대피소·구호품·물·병원 (지역팩), 위험 구역, 출처·확인일, 나침반 길 안내 |
| 스캔 | 약(기기 안 글자 인식 → 오프라인 약 목록), 식물(언제나 "먹지 마세요"), 상처(사람이 종류 선택 → 응급처치) |
| 보유품 | 사람·물·식량 → 며칠 버티나, 물 만들기(끓이기·락스·햇빛), 가진 재료로 식사(불 없이·물 없이) |
| 응급처치 | 10개 주제, 한 화면에 한 단계, 듣기(기기 음성), 위험 신호, 출처 |
| 계획 | SOS(손전등·경보음·화면·진동 모스부호, 좌표), 가족 집결지 + QR 공유, 비상 배낭, 불발탄 안전 |

- 계정 없음, 분석·광고 SDK 없음, 위치·사진·가족 정보는 기기 안에만 저장
- 안드로이드 릴리스 빌드에 INTERNET 권한 없음
- 한국어·영어, RTL 레이아웃 지원 (아랍어는 레이아웃 확인용 더미)

## 실행

```bash
flutter pub get
flutter run           # 안드로이드 기기/에뮬레이터
flutter test
```

## 주의

- 지역팩 대피소 좌표는 **샘플**입니다. 실제 대피소는 `tools/build_region_pack.py`로 공공데이터포털 자료에서 만드세요.
- 응급처치·약·물 안내 문구는 IFRC·대한심폐소생협회·WHO·CDC·UNMAS 공개 지침을 바탕으로 작성했으며 **출시 전 의료 전문가 검토가 필요합니다.**
