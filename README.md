# 🧭 생존수첩 — 재난·전시 생존 가이드

전쟁이나 재난이 일어났을 때 **인터넷이 끊겨도** 쓸 수 있도록 만든 한국형 생존 앱입니다.
휴대폰 브라우저로 한 번 열고 **홈 화면에 추가**하면 기기에 저장되어 오프라인에서도 동작합니다(PWA).

> 순수 HTML/CSS/JS로 만들었습니다. 빌드 과정이 없고, GitHub Pages 같은 정적 호스팅에 그대로 올리면 됩니다.

## 기능

### 🆘 긴급
- 119 · 112 · 1339 · 110 · 122 · 109 바로 걸기
- **내 위치** (GPS — 인터넷 없이도 동작) → 문자로 보내기 / 복사 / 공유
- **민방위 경보별 행동요령**: 경계경보 · 공습경보 · 화생방경보 · 경보해제 (사이렌 소리 구분 포함)
- 긴급 도구: 🔦 손전등(흰 화면) · 🆘 SOS 모스부호(빛+소리) · 📣 호루라기 · 🪪 의료 정보 카드(구조자에게 보여주기)

### 🗺️ 지도
- 주변 **대피소 · 지하철역 · 응급실 · 병원 · 약국 · 자동심장충격기(AED) · 경찰 · 소방서 · 식수 · 마트 · 주유소 · 화장실** 검색 (OpenStreetMap)
- 거리 · 방향 · 도보 시간, 카카오맵 길찾기 연결
- 검색 결과와 본 지도 타일은 **기기에 저장 → 오프라인에서도 확인**
- 📌 가족 집결지 · 물 받는 곳 · 위험 지역 등 내 장소 표시
- ⚠️ OSM에는 정부 지정 민방위 대피소가 빠져 있을 수 있어 국민재난안전포털 / 안전디딤돌 앱 안내를 함께 표시

### 🩹 응급처치 (오프라인 내장, 15개)
심폐소생술(박자 메트로놈 포함) · 심한 출혈·지혈대 · **총상·파편상·폭발 부상(MARCH)** · 상처 소독·감염 · 화상 · 골절·부목 · 기도 막힘 · 쇼크 · 회복자세 · **화학물질 제독** · **핵·방사능 낙진** · 저체온증 · 열사병 · 탈수·경구수분보충액 · 물 정수
— 증상/상황 단어로 검색 가능

### 📷 사진 분석 (온라인 + API 키 필요)
카메라로 찍어서 물어보기 — Claude AI(`claude-opus-5-5`)가 분석합니다.
- 💊 **약·의약품**: 약 이름, 성분, 효능, 복용법, 주의사항, 유효기간
- 🌿 **식물·약초·버섯**: 후보 식별, 닮은 독초, 식용/약용 여부 (버섯은 절대 식용 판정 안 함)
- 🩹 **상처·부상**: 상처 종류·심각도, 지금 할 응급처치, 병원이 필요한 기준
- 🔎 **기타**: 물·음식 상태, 물건 활용법, 위험물 여부
- 결과는 기기에 저장되어 오프라인에서도 다시 볼 수 있음

설정(⚙️)에서 [Anthropic API 키](https://console.anthropic.com/settings/keys)를 입력해야 합니다. 키는 기기 브라우저에만 저장되고, 사진은 분석을 위해 Anthropic 서버로만 전송됩니다. 사용량만큼 요금이 부과됩니다.

### 🎒 준비
- **생존배낭 체크리스트** (국민재난안전포털 기준)
- **상비약 관리**: 유효기간 임박/만료 알림
- **가족 계획**: 1·2차 집결지, 대피소, 연락 거점, 비상 연락처, 내 의료 정보
- **물·식량 계산기**: 인원 × 일수

모든 개인 데이터는 이 기기의 브라우저(localStorage)에만 저장됩니다.

## 실행

```bash
python3 -m http.server 8000
# 휴대폰에서 쓰려면 https로 배포하세요 (GPS·카메라·오프라인 기능은 https 또는 localhost에서만 동작)
```

GitHub Pages: 저장소 Settings → Pages → 브랜치 선택 → 생성된 https 주소를 휴대폰에서 열고 "홈 화면에 추가".

## 구조

```
index.html            화면
css/style.css         스타일 (어두운 화면 = 배터리 절약)
js/content.js         응급처치·민방위 경보·체크리스트 내용 (오프라인 내장)
js/places.js          주변 시설 검색 (Overpass API)
js/ai.js              사진 분석 (Anthropic SDK, 브라우저에서 직접 호출)
js/app.js             화면 동작 · 저장
sw.js                 서비스 워커 (오프라인 캐시, 지도 타일 최대 1,500장)
manifest.webmanifest  홈 화면 앱 설정
vendor/leaflet/       지도 라이브러리 Leaflet 1.9.4 (BSD-2)
```
